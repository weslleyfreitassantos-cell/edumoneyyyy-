# Learning Center V4 UI Audit

This audit keeps the current routes and data contracts while making the next
interaction easier to find. It is intentionally additive and does not change
academic calculations.

## Student Central de Estudos

- **KEEP:** greeting, search, subject discovery, daily plan, guided journey,
  progress, error notebook, simulations, collections and adaptive guidance.
- **MOVE forward:** the first viewport should answer “what do I do now?” with
  the daily/guided plan before the larger catalog.
- **MERGE visually:** progress counters remain compact supporting context rather
  than competing with the primary study action.
- **REPLACE later:** generic empty states should distinguish no evidence from a
  graph-only skill and from a content-ready skill.
- **REMOVE from UI:** duplicate diagnostic explanations and any action that has
  no destination.

## Teacher Central Pedagógica

- **KEEP:** published activities, students, class gaps, guided interventions,
  heatmap, question bank and package assignment.
- **MOVE forward:** student attention and class gaps should precede authoring
  forms; the teacher can then choose a targeted reinforcement.
- **MERGE visually:** adaptive insight and guided-session alerts share a clear
  diagnostic section without hiding counts or reasons.
- **REPLACE later:** large all-in-one authoring flow with explicit tabs/routes
  for overview, students, map, content and activities once the backend contracts
  are stable.

## Current limitation

V4 content and readiness are currently representative rather than the full
campaign scale. The UI audit records the destination without claiming that all
180+ leaves or all final route splits already exist.
