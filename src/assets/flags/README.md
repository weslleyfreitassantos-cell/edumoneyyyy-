# Tec Idiomas flag assets

The US, ES, and KR SVG artwork in this directory is sourced from the `svg/` folder of [hampusborgos/country-flags](https://github.com/hampusborgos/country-flags) at commit `c09927e63705529bbf59ca6684cd9b23225dddad`.

That project describes the assets as accurate flag renders sourced from Wikimedia Commons and states that flags are in the public domain, while noting that national-law restrictions on use may still apply. The SVGs are bundled locally with the frontend; the application does not fetch them from a third-party host at runtime.
