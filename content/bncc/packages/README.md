# Conteúdo autoral em pacotes

Os manifestos desta pasta são derivados do `tec-escola-core-v4` e servem como
ponte versionada para a fábrica de conteúdo. Eles não são catálogo oficial da
BNCC e não promovem automaticamente um código oficial a habilidade canônica.

Um item só fica `TECH_VALIDATED` quando a skill é `ADAPTIVE_READY`, possui aula,
possui pelo menos quatro questões e todas as peças estão marcadas como
`TECH_VALIDATED` ou `AUTHORED`. Conteúdo `SCAFFOLD` permanece visível para o
curador, mas não é elegível para disponibilidade automática.

Comandos:

```bash
npm run bncc:content-packages
npm run bncc:validate-content-packages
```
